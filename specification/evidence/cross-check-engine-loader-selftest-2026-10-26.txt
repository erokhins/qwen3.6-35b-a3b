# CPU-only, no device lock, no timing taken. This is the witness file: it holds the honest arm AND one
# arm per injected disagreement, and every one of the 10 injections turns a NAMED check red. A check
# that cannot fail is no check (pitfalls/40-gates-and-admissions.md §empty-parse-PASS), so the file also
# records parsed_xcheck == printed_checks for all 11 arms -- an arm whose parser dropped a line, or
# parsed nothing, could not have printed this RESULT PASS.
# Injections and what each one is a model of:
#   expert_off_by_one / expert_len_by_one  the prototype's expert address moves by a byte -> red
#   axis_swap          ruler B claims dims[0] is the expert axis (AGENTS.md prediction 3's failure)
#   refusal_ignored    a ruler that WRAPS an out-of-range expert id instead of refusing it
#   width_table_stale  a block table out of date by 16 B/256 (the real Q5_K-at-5.0-bpw bug)
#   alignment_wrong    the packing alignment is not the file's general.alignment
#   file_off_shift     one tensor's header offset lies by 32 B
#   type_swap          two type-id tables disagree about Q5_K vs Q6_K
#   population_shrunk  the sampled population is smaller than geometry derives -> denominator is red
#   empty_ruler        an empty parse may never print PASS
