# Question: arm=stub printed "missed 192 allowed stages, derived 184". Which number is
# right? Answer: 192. Neither tally was trusted; the gate prints one row per case listing
# the stages the differ actually saw move, so the population was rebuilt from those rows
# and compared against the contract tables. The 8 localises to exactly one section,
# router_softmax_bf16, whose residual is exactly {topk_ids, expert_raw} x 1 case x 4 blocks.
#
# Why those two stages are licensed, from the dataflow in speccheck/moe_ref.py:
#   §route          — logits -> softmax(softmax_dtype) -> torch.topk -> ids. A bf16 softmax
#                     can reorder the probabilities, so it can change WHICH experts are in
#                     the top-k. When it does, the reported ids themselves move.
#   §expert_gather  — read_ids are those ids, and pick(e) indexes gate_up[e]/down[e] by
#                     them, so a changed id reads a DIFFERENT 6.0 MiB expert: expert_raw
#                     moves with it, then routed_sum, then combined_out.
#   When the selection does NOT flip, both stages must stay bit-identical — so they are
#                     conditional on the discrete fact, never unconditional. The fact here
#                     is genuine: 4/4 blocks flip (honest ids_flips 4, and topk_ids appears
#                     in the moved-stage column of exactly the 4 router rows and no other).
# Why 184 was the wrong one: it is |AFFECTED| x the case list x 4 blocks = 46 x 4, and
#                     AFFECTED is only the unconditional half. The runtime contract
#                     (allowed_stages) had been adding {topk_ids, expert_raw} from a bare
#                     literal the derivation could not see. Two spellings of one contract;
#                     pitfalls/40 §two self-consistent layouts joined by a branch.
# Third, independent witness that 192 is the truth: arm=crossed injects exactly one
#                     must-not-catch breach per case, so its stage_diffs must be honest +
#                     60. Printed: 192 + 60 = 252. And arm=honest reads
#                     must_not_catch_violations 0 with localised 60/60, i.e. the moved set
#                     equals the allowed set case for case — which pins |allowed| at 48 per
#                     block, not 46.
