# tools/ — provenance of the copied probes

Every file here except `doc_ref_check.py`, `hostmap_probe.cpp`, `pin_hold.cpp`, `pin_pair.sh`,
`quant_scenarios.py`, `gguf_header_types.py`, `gguf_reader.py`, `audit_published_quant.py`,
`build_llama.sh` and
`halogen_gate.sh` (all ten are this
repo's own) is a **verbatim
copy** made on 2026-10-26 from the 0.8B engine repo, so that this project can re-measure and re-gate without
depending on that repo at read time (rule: `pitfalls/60-docs-and-citations.md`).
Keeping the copies pristine means they can be diffed against upstream later; **do not edit them to remove old
references** — record the caveats here instead.

| `quant_scenarios.py` | **written here (2026-10-26)**: family census from `checkpoints/*.config.json` validated against the index `total_size`, then residency + per-token + tok/s ceilings per quantization policy | ceilings are bytes ÷ bandwidth, not engine measurements; `--census` must print a delta against `total_size` of a couple of %, otherwise the shapes drifted (`checkpoints/README.md`). No policy row uses Q5_K, so policy A's figures did not move when that row was corrected. **Rebuilt 2026-10-26**: the census no longer comes from a hand-written architectural model at all — it derives from the pinned GGUF's tensor records plus the element counts of index names the artifact does not carry (the draft block, derived as *names with no entry in `bf16_census.MAP_HF_GGUF`*, not a typed `mtp.` list), closing index-vs-`total_size`, census-vs-index per family, text totals and parsed-vs-declared records to **0 B**; policy rows name ggml *types* and price them through `ggml_block_geom.row_bytes()`, so no bpw literal exists to be mistyped. | `ggml_block_geom.py` | **written here (2026-10-26)**: reads block element counts and byte sizes out of `engines/llama.cpp/ggml/src/ggml-common.h` at run time (struct member sums, including inline `union { struct {...} }` accessors, cross-checked against each struct's own `static_assert`, macros evaluated by a small recursive-descent expression parser) and is the single source of width arithmetic for `gguf_reader.py`, `gguf_header_types.py`, `quant_scenarios.py` and the audit | written because two tools hand-typed the same width table and one row was wrong (Q5_K at 5.5625 bpw where the struct is 176 B/256 = 5.5). A struct whose member sum disagrees with its own `static_assert` aborts the run; a struct the scanner cannot read (nested unions it does not model) is reported and never priced. Element-count-per-block is a claim about the type, not a header reading, and is witnessed instead by `check_file()`'s size identity over all 733 tensors. `--emit` writes `quantization/evidence/audit-block-geometry-2026-10-26.md`; `--check PATH` runs the identity against a real file |
| `gguf_reader.py` | **written here (2026-10-26)**: stdlib GGUF header parser + F32/Q8_0/Q4_K/Q5_K/Q6_K dequantizers + reference quantizers for the floor probe, transcribed from `engines/llama.cpp` `ggml/src/ggml-common.h` and `ggml/src/ggml-quants.c` at `d327bf1f` | it gates the data section: `Gguf.open_data()` raises unless the caller holds the selftest token, so a section that has not proven the gate cannot read a value byte. First green: 30 checks, 0 findings, 1147 units / 4052 cases / 10 launches (`prototype/q4k_dequant/results.md`) | **correctness only**: no timer in `gate.py`, no `ms`/`GB/s`/`tok/s`, no warm loop; the wrapper prints the lock record (command line, wall pair, `util`, the words `no timing taken`) and it alone acquires the lock — `gate.py` has zero references to the lock tool, `grep -c gpu_lock gate.py` prints 0 and the wrapper prints that fact as `LOCKREF`, and `--selftest`/`--check-only` take no lock because they touch no device. It refuses to run on a stale audit marker, mirroring `audit_published_quant.py §require_selftest` without writing to step 1's ordering log. |

| `prototype/moe_router/` (`moe_router_kernels.h`, `moe_router.hip`, `host_probe.cpp`, `oracle_arm.py`, `gate.py`, `gate`, `build.sh`) | **written here (2026-10-26), not a copy**: the MoE router as R1→R5 (logit dot, softmax, top-k, renorm, bf16 cast) plus the weighted combine, run on the iGPU (`gfx1151`) and judged word-for-word against `speccheck/moe_ref.py` over the pinned dumps of `checkpoints/dump-manifest-2026-10-26.json`, with 12 injected misreadings as the must-catch set and `mr_mode_reaches` (asked of the compiled predicate via `moe_router --reach-table`, not mirrored) as the must-not-move half. First green: 40 checks, 0 findings, 3224 cases / 19,344 field comparisons / 13 launches / 128 pinned + 12 derived rows (`prototype/moe_router/results.md`) | **correctness only**: no timer in `gate.py`, no `ms`/`GB/s`/`tok/s`, no warm loop; the wrapper prints the lock record (command line, wall pair, `UTIL_BEFORE`/`UTIL_AFTER`, the words `no timing taken`) and it alone acquires the lock — `gate.py` has zero references to the lock tool, `grep -c gpu_lock gate.py` prints 0 and the wrapper prints that as `LOCKREF`; `--selftest`/`--check-only` take no lock because they touch no device. Driver stdout goes to `work/*.log` and is parsed from the file, never piped; every parser requires parsed == printed and matches tags as whole words (`PLAN` cannot swallow `PLANCHECK`). The same `moe_router_kernels.h` is compiled twice on purpose (hipcc for the device, g++ for `host_probe.cpp`) and both arms are judged by the **same** Python judges, so `--check-only` proves the judges with zero device work — that is how the output-widening bug (`mr_bits_to_f32` on a `uint16_t` instead of a shift) and the self-comparison bug (`cmp_off` added to an already-offset buffer base) were caught before the device was touched. Every band is derived: the R2 certificate bound is `(2(E-1)+1)·2⁻²⁴/(1-(E-1)2⁻²⁴)` from the header's `MR_E` and IEEE binary32, with a witness that a 3x-bound row is rejected and a legitimate drift accepted; the bf16 cross-arm ruler counts **bf16** steps, not f32 ones. `--max-rows` cuts the **sample** and prints `CUT ...`, never an assertion, and the sample (cases, arms, field comparisons, elements, launches) is declared before any device work. |
